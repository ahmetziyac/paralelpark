# Park Ustası

Paralel ve L parkı, trafik kurallarına uygun öğreten tek dosyalık tarayıcı oyunu.

- Tanıtım sitesi: <https://ahmetziyac.github.io/paralelpark/>
- Oyun (doğrudan): <https://ahmetziyac.github.io/paralelpark/oyun.html>

## Dosyalar

- `index.html` — tanıtım sitesi (ana sayfa)
- `oyun.html` — oyunun kendisi (tek dosya, dış bağımlılık yok)

## Yayınlama

`main` dalına push yaptığında GitHub Pages siteyi otomatik günceller.

İçerik eğitim amaçlıdır; gerçek ehliyet eğitiminin yerine geçmez.
